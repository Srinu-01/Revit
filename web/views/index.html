About Revit

Revit is a powerful reverse DNS lookup utility that allows you to quickly discover domain names associated with IP addresses.

Originally developed as a command-line tool, Revit now offers this intuitive web interface for performing lookups directly from your browser.

Features

  • Single and batch IP lookups
  • File upload support
  • Custom DNS resolvers
  • Adjustable concurrency
  • Command-line interface
Command-line usage: 
$ revit -i "8.8.8.8"
$ revit -l ip_list.txt
$ cat ip_list.txt | revit
$ revit -c 20 -r 1.1.1.1 -l ips.txt
